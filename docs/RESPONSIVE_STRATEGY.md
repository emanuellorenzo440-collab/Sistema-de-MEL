# Estrategia Responsiva

## Objetivo

El sistema debe poder usarse comodamente desde celular, tablet y escritorio. La captura de datos desde campo debe funcionar especialmente bien en telefono.

## Breakpoints actuales

- Escritorio: layout con sidebar fija y area amplia de trabajo.
- Tablet: navegacion superior desplazable y grillas de dos columnas.
- Celular: una columna, botones apilados y tablas con scroll horizontal.

## Reglas para celular

- Toda pantalla debe funcionar en una sola columna.
- Ningun texto debe salirse de su contenedor.
- Los botones deben tener altura suficiente para tocarse facilmente.
- Los formularios deben evitar columnas multiples.
- Las tablas deben permitir desplazamiento horizontal sin romper layout.
- Los filtros deben apilarse.
- La navegacion debe ser accesible sin ocupar toda la pantalla.

## Flujos prioritarios en celular

1. Crear reporte.
2. Descargar o consultar formularios.
3. Subir archivo completado.
4. Ver estado de reportes.
5. Revisar alertas principales.

## Criterios de aceptacion

- La app no debe tener solapamientos visuales en 360px de ancho.
- Los controles deben ser tocables sin zoom.
- El usuario debe completar un reporte desde celular.
- El dashboard debe mostrar metricas clave sin perder legibilidad.
- Los estados deben entenderse sin depender solo del color.
